## What was built this session

### 1. `experiments/EXP-052_m1_circuit_svd_factored/`
New experiment folder. The OLD `scripts/deepseek_circuit_svd.py` was `git mv`d here as `run.py`, then overhauled. Prior results in `results/ds_circuit_full/` are the first-gen baseline we'll diff against.

**What changed vs the prior circuit SVD:**
- **Factored SVD on stacked deltas.** No more materializing the 7168×7168 `ΔOV` / `ΔQK` products. Stack `[A_d | −A_b] @ [B_d; B_b]` with rank ≤ 2·512 = 1024, thin-QR each, SVD the tiny 1024×1024 core, map back. Verified numerically: reconstruction rel-err 1e-6, σ match to float32 precision, U/V orthonormal to 1e-6.
- **RMSNorm γ folded into B projections.** Previously loaded but ignored — the γ is a learned diagonal that carries backdoor signal; now absorbed into `q_b_proj` and `kv_b_proj`. `1/RMS(x)` can't be folded (input-dependent) and is intentionally omitted.
- **File-descriptor leak fixed.** `safe_open` now wrapped in `with …` in `load_tensor`.
- **`plot_token_bars`** now uses real projection scores (`input_top_scores` / `output_top_scores`), not rank indices.
- **Cross-layer coherence plot** consumes cached `(U₀, V₀)` collected during the main loop — no per-layer weight reload.
- **`plot_layer_aggregate`** (NEW) — `Σ_h |ΔOV_h|²` + `Σ_h |ΔQK_h|²` + `max_h |ΔOV_h|` per layer. First-pass localization diagnostic.
- **Concentration score `σ₁²/Σσᵢ²`** computed per head and stored in the JSON alongside norms.
- **`plot_joint_norm_concentration`** (NEW) — the core detector:
  - 2D scatter `(‖ΔOV‖, concentration)` with NE-corner flagging (top 5% on both) — rank-1 backdoor signature.
  - Within-layer robust z-score of `log‖ΔOV‖` via median + 1.4826·MAD. Layers have very different natural scales so global z-scores mix noise; MAD is robust to heavy tails.
  - Union of NE-corner + `z>3` heads dumped to `flagged_heads.json`.
- **`raw_module_decomposition`** (NEW) — for each flagged head, computes `‖ΔW‖_F` on each physical projection slice (`q_a_proj`, `kv_a_proj_with_mqa`, `q_b_proj_h`, `kv_b_proj_h`, `o_proj_h`) so we know which weights to touch for backdoor removal.
- **`--no-fold-ln`** flag added for ablation.
